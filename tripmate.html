TripMate-AI

Agentic travel planner

Overview

TripMate-AI is a multi-agent travel planner built on LangGraph. A Supervisor coordinates specialist agents, Guardrails keep requests in scope, and the traveller iteratively refines the plan.

01

Agents

Supervisor, Guardrails and specialised agents for transit, hotels, weather and budget-aware itinerary generation, with dynamic destination discovery and recommendation.

02

Orchestration

Stateful MCP tool orchestration with parallel agent execution, structured outputs and multi-provider LLM fallbacks.

03

Ranking and refinement

Deterministic preference-based ranking, with human-in-the-loop iterative plan refinement.
